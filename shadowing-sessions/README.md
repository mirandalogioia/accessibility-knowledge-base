# Shadowing Sessions

Notas de sesiones de shadowing: auditorías de accesibilidad, testing con usuarios con discapacidad, revisiones guiadas por especialistas, u otras instancias de observación directa dentro del programa.

## Subfolders

| Folder | Contenido |
|---|---|
| `raw-inputs/` | Notas tomadas durante la sesión, grabaciones o transcripciones sin editar |
| `intermediate/` | Notas organizadas por sesión, con observaciones agrupadas por tema |
| `latest/` | Findings consolidados por sesión, listos para alimentar `dualboot-findings/` |
