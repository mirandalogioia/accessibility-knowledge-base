# Resources

Links y recursos externos de referencia sobre accesibilidad digital, recopilados durante el programa de weAAAre, las sesiones de shadowing y la investigación propia.

| Title | URL | Category | Notes |

| WCAG 2.2 Understanding Docs | https://www.w3.org/WAI/WCAG22/Understanding/ | Standard | Ver resumen traducido completo (87 criterios) en [`wcag22-understanding/`](wcag22-understanding/README.md) |

| WAI Tutorial — Form Notifications | https://www.w3.org/WAI/tutorials/forms/notifications/ | Standard | Referenciado en el Módulo 2 de weAAAre (errores, foco, lector de pantalla). Ver resumen en [`wai-tutorial-form-notifications.md`](wai-tutorial-form-notifications.md) |
