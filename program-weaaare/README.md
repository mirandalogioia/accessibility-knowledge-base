# Program: weAAAre — Diseño Accesible

Notas y materiales del programa **"Diseño Accesible"** de weAAAre: clases, ejercicios, apuntes y takeaways a medida que avanzo en el cursado.

## Subfolders

| Folder | Contenido |
|---|---|
| `raw-inputs/` | Apuntes crudos de clase, transcripciones, capturas de slides, ejercicios sin editar |
| `intermediate/` | Notas organizadas por tema/módulo, todavía en proceso de síntesis |
| `latest/` | Resumen consolidado por módulo/tema, con los aprendizajes clave ya depurados |
