# Artículos Externos

Artículos interesantes sobre accesibilidad que voy encontrando por fuera del programa (no son material del curso, aunque a veces los recomienden ahí).

## Subfolders

| Folder | Contenido |
|---|---|
| `raw-inputs/` | Texto extraído tal cual del artículo original (capturas, links, PDFs) |
| `intermediate/` | Resumen sintetizado de cada artículo |
| `latest/` | Versión consolidada, si se decide elaborar sobre el tema (pendiente) |

- `intermediate/pokemon-pauta-2-3-accesibilidad-summary.md` — resumen: el incidente de Pokémon de 1997, epilepsia fotosensitiva, cómo derivó en la Pauta 2.3 de WCAG 2.0 (convulsiones y reacciones físicas) con sus criterios técnicos (2.3.1, 2.3.2), y la aclaración de terminología ("crisis", no "ataque").
