# Accessibility Knowledge Base

## Propósito

Este repositorio centraliza mi proceso de aprendizaje en **accesibilidad digital** mientras hago el programa **"Diseño Accesible"** de weAAAre.

La idea es ir guardando todo lo que voy aprendiendo — clases, sesiones de shadowing, investigación propia con IA — en un solo lugar ordenado, para que al final del proceso pueda:

1. Consolidar los **findings** más relevantes (qué aprendí, qué patrones se repiten, qué errores son más comunes).
2. Convertir eso en una **propuesta de proceso y checklist de accesibilidad** para llevar al equipo de Dualboot Partners, y que sirva como punto de partida para incorporar accesibilidad en nuestros proyectos.

No es un repo de documentación de producto ni sigue el framework DB90 — es una base de conocimiento personal de aprendizaje, con salida orientada al equipo.

## Convención de carpetas

Las carpetas de contenido (`program-weaaare/`, `shadowing-sessions/`, `ai-research/`, `dualboot-findings/`) comparten la misma estructura interna:

| Subfolder | Uso |
|---|---|
| `raw-inputs/` | Material sin procesar: notas crudas, transcripciones, capturas, links sueltos |
| `intermediate/` | Notas en proceso de síntesis, todavía no son la versión final |
| `latest/` | Versión más actualizada y consolidada, lista para reutilizar o compartir |

El contenido fluye en una sola dirección: `raw-inputs/` → `intermediate/` → `latest/`.
